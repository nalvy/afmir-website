# afmir.se website

Source of the afmir.se site, built automatically by GitHub Pages.

- Each page is a Markdown file: `index.md` (Home), `technique.md`, `papers.md`,
  `software.md`, `labs.md`, and `tapir/index.md`.
- The top menu is set in `_config.yml` under `header_pages`.
- Screenshots for the TAPIR page go in `tapir/img/`.
- To edit a page: open the file on github.com, click the pencil icon, edit,
  then "Commit changes". The site updates within a minute or two.
